# GitHub Issues - TanStack Query

Proyecto desarrollado en React con TanStack Query

## Configuración inicial del proyecto

1. Clonar el repositorio
2. Intalar las dependencias `npm install`
3. Copiar archivo .env.template y renombrarlo a .env
4. Iniciar servidor de desarrollo `npm run dev`

## Tecnologías usadas

- React
- Typescript
- TanStack Query
- TailwindCSS
- React Router 6+
- React Icons
